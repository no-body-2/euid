# EUID (Emoji Unique Identifier)

**EUID (Emoji Unique Identifier)** 는 기존의 UUID, CUID와 같은 영숫자/16진수 기반 식별자 체계를 넘어, **유니코드 이모지(Emoji)를 활용해 시각적 직관성과 인간 친화성을 극대화한 고유 식별자(ID) 생성 기술**입니다.

## Key Features

* **높은 정보 밀도 (Base1024 엔트로피)**
  * 1,024개의 엄선된 단일 이모지 세트를 기반으로 하여, 문자당 약 10비트($2^{10}$)의 엔트로피를 부여합니다.
  * 적은 글자 수로도 강력한 무작위성과 높은 충돌 저항성을 제공합니다.

* **인간 중심의 관측 가능성 (Human Observability)**
  * `🔥-🍕-🚀-🐱`와 같이 인간이 기억하고 구별하기 쉬운 시각 기호로 표현됩니다.
  * 디버깅 로그 확인, 대시보드 모니터링, 협업 커뮤니케이션 시 인지 부하와 오류를 대폭 낮춥니다.

* **안전한 유니코드 스펙 설계 (Strict Unicode Spec)**
  * 렌더링 깨짐(Tofu 현상)이나 글자 수 왜곡을 방지하기 위해 설계되었습니다.
  * ZWJ(Zero Width Joiner) 및 변형 선택자(VS16)가 없는 순수 단일 코드포인트(Single Codepoint) 이모지만을 사전 테이블로 필터링하여 안전하게 사용합니다.

* **미래 지향적 추상화 (Human-Centric Paradigm)**
  * 컴퓨팅 자원의 한계가 점차 사라지는 시대적 흐름에 맞춰 설계되었습니다.
  * 기계 중심의 비트 절약보다 인간의 편의, 재미(Fun), 그리고 직관성에 초점을 맞춘 차세대 식별자 패러다임입니다.
